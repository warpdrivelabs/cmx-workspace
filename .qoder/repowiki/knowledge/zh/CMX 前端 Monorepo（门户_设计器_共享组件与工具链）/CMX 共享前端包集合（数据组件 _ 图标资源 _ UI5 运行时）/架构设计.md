本模块为 monorepo 下的 packages 目录，包含三个相互独立但可组合的 npm 包，彼此通过 peerDependencies 或显式依赖协作：
- `cmx-data-comp`：核心数据组件包，以 ES module barrel（`src/index.js`）统一注册所有自定义元素并导出类；按职责划分为 `components/`（表格、表单、面板、Ignite 封装、SpreadJS 等 Web Components）、`lib/`（主从协调器、列模型、数据集、元数据、公式引擎、字段类型注册表等纯 JS 逻辑），并通过 `exports` 字段精细暴露子路径以便按需 import。
- `cmx-icon-resource`：纯资源包，集中存放 Tabler SVG/PNG 图标，并提供 `ui5` 入口将 Tabler 图标桥接到 SAP UI5 `<ui5-icon>` 命名空间（如 `tabler-outline/home`），同时支持静态资源 import 路径。
- `cmx-ui5-runtime`：UI5 + Tabler 运行时打包产物，提供 `ensureCmxUi5Runtime()` 单例加载器，在 dev 模式通过 Vite alias 直接引入源码以避免双实例，在生产构建时注入带 hash 的 chunk URL；依赖 `cmx-icon-resource` 以注入图标。
依赖方向单向：`cmx-ui5-runtime` → `cmx-icon-resource`；`cmx-data-comp` 仅声明 `@ui5/webcomponents` 为 peerDependency，不反向依赖 runtime。三个包均使用 ESM (`type: module`) 并通过 `package.json` 的 `exports` 字段控制对外 API 边界。
