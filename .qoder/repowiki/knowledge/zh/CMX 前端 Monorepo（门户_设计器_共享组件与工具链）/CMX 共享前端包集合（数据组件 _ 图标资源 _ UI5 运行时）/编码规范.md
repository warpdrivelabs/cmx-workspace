- 每个包通过 `package.json` 的 `exports` 字段精确声明对外子路径，消费方通过裸模块名（如 `cmx-data-comp/lib/cmx-master-slave.js`）按需导入而非全量引入 barrel。
- Web Components 以副作用 import 的方式在文件顶层调用 `customElements.define` 完成自注册，barrel 中仅做 re-export 类名。
- 大体积第三方依赖（如 SpreadJS / ignite-spreadsheet）采用 MutationObserver 监听 DOM 后动态 `import()` 懒加载，避免污染首屏 bundle。
- 运行时单例通过 `globalThis.__cmxUi5` 缓存，并在首次加载时返回 Promise，确保多入口场景下只初始化一次 UI5 实例。
- 跨包依赖通过 `peerDependencies`（如 `@ui5/webcomponents >=2.0.0`）声明版本约束，由宿主应用统一提供实现，避免重复打包。
