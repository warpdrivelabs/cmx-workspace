模块以 `src/main.js` 为唯一入口，按「安装全局 fetch 拦截/错误兜底 → 鉴权跳转 `/login` → 初始化 cmx-ui5-runtime → 动态 import `import-ui5-and-app.js` 注册 Portal 自定义元素 → 应用主题与语言 → reRenderAllUI5Elements」顺序启动；登录门 `login.html` 与主入口 `index.html` 通过 vite.config.js 的多 input 分别构建。

内部分层清晰：
- 运行时核心 `src/lib/mainapp.js` 暴露 `ContextHost`（键值上下文+change事件）、`Workspace`（content/explorer/property/bottom/floatview/model/inner/embed 九区域容器）和 `ActivityScope`（活动侧栏精简版），并通过 `globalThis.mainapp` 单例跨视图通信。
- 组件层 `src/components/portal-*.js` 均为自定义元素，按职责分为 Shell（ShellBar/SideNav/ContentArea/AppShell）、Workspace（workspace/dock/float/prepare/loading/profile）、管理面板（menu-editor/definition-manager/flexible-combination-manager/property-panel/log-panel）等。
- API 封装层 `src/api/*.js`（menu/domains/activities/notifications/workspace-nodes/html-pages/form-pages/iam/dam-registry）统一经 `cmx-ui5-runtime/api-client` 的 `installAuthFetchInterceptor()` 附加 Bearer token 并处理 401，业务组件不直接拼接 URL。
- AI 子域 `src/ai-workbench/` 独立组织，包含基于 SSE 的对话组件、消息存储（message-store.js）与 sse-client 服务，通过 markdown-it/shiki 渲染富文本。
- 构建配置 `vite.config.js` 使用函数式配置按 mode 加载 `.env.*`，通过 `cmxUi5RuntimeAppPlugin` 接入 UI5 runtime，并对 igniteui/tabulator/lit/shiki/markdown-it/@floating-ui 等重型库做 manualChunks/codeSplitting 精细拆分，开发期 proxy 将 `/api /rpc /trpc /sse /ws` 转发至 Rust 后端 `http://127.0.0.1:8080`。
