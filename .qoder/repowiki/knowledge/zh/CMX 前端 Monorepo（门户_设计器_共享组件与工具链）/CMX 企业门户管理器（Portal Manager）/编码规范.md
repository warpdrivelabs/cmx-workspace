- Portal 自定义元素统一放在 `src/components/portal-*.js`，通过 `import-ui5-and-app.js` 中的 `Promise.all([...])` 批量动态 import 注册，避免首屏阻塞。
- 跨视图状态共享通过 `mainapp.workspaces[wsId].context` 的 `ContextHost`（get/set/delete/on/off）进行，禁止直接裸赋值触发变更通知。
- 工作区与活动作用域的创建/销毁成对使用 `createWorkspace`/`disposeWorkspace` 与 `createActivityScope`/`disposeActivityScope`，并在 dispose 时清理 context、hosts 与 actions。
- 视图生命周期由 `registerView`/`unregisterView` 统一管理，宿主 CE 在 connectedCallback/disconnectedCallback 中调用，Dock 拖动场景通过 host 引用比对防止竞态。
- API 调用统一经 `src/api/*.js` 模块封装，并由 `installAuthFetchInterceptor()` 自动附加 Bearer token 与 401 处理，业务组件不直接拼接 URL。
- Vite 构建中对重型第三方库（igniteui、tabulator、lit、shiki、markdown-it、floating-ui）通过 manualChunks/codeSplitting.groups 拆分为独立 vendor chunk，并按优先级从高到低匹配。
