- 每个 Python 脚本以 `#!/usr/bin/env python3` shebang 开头，并通过 `ROOT = Path(__file__).resolve().parents[1]` 定位仓库根，再派生 `OUT`、`CACHE` 等输出路径。
- 对外部网页采用 `fetch(url, path)` 模式：先检查本地缓存大小阈值，不足时才发起 HTTP 请求并写回磁盘，避免重复抓取。
- 解析 ERPExplorer/Data Panda 表格时复用同一套 `TdTableParser` 继承自 `html.parser.HTMLParser`，通过 `handle_starttag/handle_endtag/handle_data` 三钩子收集 `<tr><td>` 单元格文本。
- 表字段统一建模为 `@dataclass Field(pos, name, english, domain, checktable, data_element, dtype, length, decimals, values)`，便于在不同生成器间共享数据结构。
- 生成 HTML 输出时使用 `html.escape` 转义用户/远端数据，并以内联 CSS + 搜索框的方式渲染可交互的离线参考页。
- Shell 脚本使用 `set -euo pipefail` 严格模式，并通过 `declare -A` 关联数组维护服务到仓库的映射，参数缺失时用 `${1:?用法: ...}` 快速报错。
