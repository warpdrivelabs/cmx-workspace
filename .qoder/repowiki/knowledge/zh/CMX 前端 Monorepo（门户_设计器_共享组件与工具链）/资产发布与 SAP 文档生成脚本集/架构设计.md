本模块由两类独立脚本组成：
- 发布类（`scripts/publish-assets.sh`）：以 `cmx-container/assets/<svc>` 为唯一真源，按服务名（portal/model/mdm/flow/report/rules）映射到对应主应用仓目录，对 `web/`、`data/` 下的顶层子目录执行整目录替换、顶层散文件覆盖拷贝，并提示未托管条目；通过 `declare -A REPO` 维护服务→仓库映射。
- 校验类（`scripts/check-asset-ownership.py`）：扫描 `assets/<svc>/web/ui-native/index.json` 与 `web/ui-html/index/*.pages.json`，依据每服务的 id 前缀白名单（`PREFIX` 字典）校验归属、跨仓去重及 html v2 行字段不被 portal/model 前缀污染。
- 文档生成类（`generate_acdoca_html.py`、`generate_erpexplorer_fico_catalog.py`、`generate_sap_fi_real_structures.py`）：统一通过 `urllib.request` + 自定义 `HtmlParser` 子类解析 ERPExplorer/Data Panda 页面表格，缓存至 `docs/.cache`，输出静态 HTML 到 `docs/`；其中 ACDOCA 脚本硬编码 511 字段数断言，FICO catalog 使用评分函数 `fico_score` 筛选候选表并对 `CORE_TABLES` 中的核心表拉取完整字段，FI real structures 则读取 `../../../../../../cmx-portal-manager` 与 `sap_fi_doc_meta_v1.json` 作为真实元数据源。
- `.agents/skills/` 存放 Claude Agent 技能定义，`.claude/settings.json` 仅声明允许执行的 Bash 命令白名单。
