模块按里程碑（M0–M26）分层组织在 src/ 下，通过 src/index.ts 统一 re-export 公共 API：
- core/：无 DOM 的数据模型层，包含 Workbook/Worksheet/Cell/Range/SparseMatrix/Style/SelectionModel/EditCommands/Clipboard/FillEngine/find/sort/validation/dateSerial/address，是后续所有层的单一事实源。
- formula/：纯逻辑公式引擎，Tokenizer → Pratt Parser → Evaluator → DependencyGraph（三色环检测 + 增量重算），内置函数按数学/财务/统计/数据库/文本/工程等子目录组织，并通过 CustomFunction 支持 QM/QC/JE/FS/REF 报表取数。
- render/：面向最小 RenderContext2D 接口的 Canvas 渲染与交互层，SheetGeometry（getCellRect/hitTest 严格互逆）、PaneLayout（冻结/尾冻结/拆分三 band）、Viewport、SheetRenderer、InteractionController、CellEditor、SheetTabStrip、condFormat、numFmt、chart/{drawChart,drawSparkline}、overlay/FloatingLayout、ScrollbarLayout。
- io/：零依赖导入导出，以中性 JSON 快照（snapshot.js）为单一事实源，围绕它实现 xlsx/csv/ssjson/zip+deflate/inflate/exportHtml/exportPdf/pdf/paginate。
- element/：<cmx-megasheet> Web Component 入口与 ReportModel 输入契约，消费方通过 setReportModel / loadWorkbook 等约 150 个方法交互。
依赖方向单向：element → render/formula/io → core；core 不依赖任何上层。构建产物由 tsc -p tsconfig.build.json 输出至 dist/，package.json 中 exports 仅暴露 ./dist/index.js 及类型声明。
