模块以 Vite 为构建工具，入口 `src/main.js` 负责鉴权、加载 cmx-ui5-runtime、应用主题并懒加载业务模块；`src/import-ui5-and-app.js` 按序注册标签元数据与插件（models/data/ignite/thin），再挂载根组件 `designer-app`。

内部按职责分层：
- `components/` 实现 UI 层，顶层 `designer-app` 通过 `designer-app-shell-template.js` 定义三栏布局（左侧调色板+树、中央画布/源码+多 Tab、右侧 Inspector），子目录 `designer-app/`、`designer-inspector/`、`designer-page-data/` 分别承载工作区、检查器与页数据面板。
- `lib/` 提供跨组件共享能力：`library` 单例（UI5 库适配器）、`api-client`（带 Bearer Token 的 fetch 拦截）、`auth`、`plugin-registry`、`codemirror-loader` 等。
- `metadata/tags/` 以 JSON 描述可拖拽的 HTML/UI5 标签及其属性、事件预设，由 `tag-registry.js` 聚合并通过 `vite-designer-metadata-plugin.js` 在构建时注入。
- `plugins/` 是扩展点，各 `cmx-*-plugin.js` 向设计器注册自定义模型/Inspector/数据源。
- `api/` 封装与后端的 REST/gRPC 调用（页面、注册表、服务目录、工作区节点）。
- `debug-portal/` 是独立调试窗口应用，通过 `activities-api.js` 与主设计器通信。

依赖方向单向：components → lib/api/metadata/plugins → 外部 cmx-ui5-runtime/cmx-data-comp；Vite alias 将 `cmx-*` 包指向 monorepo 源码以便开发期热更新。
