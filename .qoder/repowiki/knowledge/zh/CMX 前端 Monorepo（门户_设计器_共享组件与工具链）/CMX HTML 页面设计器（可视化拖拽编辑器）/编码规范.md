- 组件以自定义元素形式组织，模板字符串集中放在 `*-template.js` 中（如 `designer-app-shell-template.js`），样式集中在 `*-style.js`，逻辑文件与模板分离。
- 通过 `plugins/cmx-*-plugin.js` 以插件形式向设计器注册功能（模型、Inspector、数据源等），新增能力无需修改核心代码。
- 可拖拽标签以 `metadata/tags/<namespace>/<tag>.json` 的声明式 JSON 描述，再由 `tag-registry.js` 动态聚合，新增标签只需添加 JSON 文件。
- 对外 API 访问统一经由 `lib/api-client.js` 的 `installAuthFetchInterceptor` 注入 Bearer Token，并在 `main.js` 中全局启用，避免在各组件重复处理鉴权。
- Vite 构建使用函数式配置并按 mode 加载 `.env.*`，通过 `loadEnv(mode, __dirname, '')` 暴露所有前缀变量，后端地址由 `CMX_APP_BASE`/`CMX_VITE_BACKEND` 环境变量控制。
- 测试用例集中于 `src/__tests__/`，使用 Vitest + jsdom，文件名与被测模块一一对应（如 `html-utils.test.js` 对应 `utils/html-utils.js`）。
