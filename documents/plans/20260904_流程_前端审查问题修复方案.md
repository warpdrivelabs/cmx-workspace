## 二、P1 应修（6 项，均双份或已定位）

1. **发布/保存双击连发**：`doPublish`/`doSave` 无 in-flight 防抖、按钮无 disabled——双击一次版本 +2。修：提交前置 busy 标志 + 按钮 disabled。
2. **ops-console SSE 泄漏**：`state.es` 页面离开不 abort，后台每个事件触发 3 请求永续。修：宿主清空时 abort（与 P0-1 同一卸载钩子体系）。
3. **`loadDef` 竞态**：快速连点两定义，慢响应后到覆盖画布、`selectedKey` 失配。修：请求序号（最新者胜）。
4. **幽灵协同**：`newDiagram`/`doImport`/`doSaveAs` 切定义不 `stopCollab`，心跳/编辑广播仍发旧 defKey。修：三入口统一先 stopCollab。
5. **每键击一次 HTTP**：条件构建器文本框绑 `'input'`——一个字 = 一条 undo 命令 + 一次协同 POST。修：改 `'change'` 或 300ms 去抖。
6. **死信伪报**：ops-console `loadDeadLetters` 失败静默、页面显示"无死信作业"——运维页把故障显示成健康。修：失败置错误态（重试入口），与空列表区分。

## 三、P2 建议（四类）

### 3.1 性能/请求
- `definitions/list` 全表拉取三处各自缓存互不共享（todo-center `loadFullDefinition` / task-form `loadDefinition` / cr-form `ftDefinition`）——改走已存在的 `POST /definitions/detail {key}` + globalThis 共享缓存（对齐 `__cmxFlowUsers` 先例）。
- event-delivery-monitor 30s 轮询换 SSE（引擎 `/api/flow/v1/events` 已有流，需补投递状态事件类型）。
- todo-center `openTransferDialog` 每次重拉 users 列表，未复用快照。

### 3.2 重复代码上收
- todo-center 与 task-form 的审批视图模型（`buildApprovalSteps`/`buildApprovalViewModel` 约 230 行近同构双副本，靠版本串运行时去重）——循 cmx-flow-trail 先例上收 cmx-data-comp。

### 3.3 死代码清理
- def-workbench 成片残留：`damFilterHtml`/`defPagerHtml`/`subflowCount`/`gotoDefPage` 全无有效调用，`bind()` 列表绑定空挂；
- 双份 `openVarDialog`/`closeVarDialog`/`varDialogHtml`、`state.canvasHost` 只写不读；
- todo-center `ccToTodo` 零引用；`fmtT/enc/fmtD` 等零引用散件；
- 轨迹上收后的 `.tf-flow*/.tf-cmt*/.todo-flow*/.todo-cmt*` CSS 残块。

### 3.4 防御性
- definition-manager / event-subscription-manager 头注释仍写旧 GET 接口口径（注释漂移）；
- ops-console `explorerHtml` 状态枚举兜底分支补 esc；
- workbench `ensureBpmnJs` 失败后 rejected Promise 永不重试；
- `subSave` 首存后 detail 重载 `catch{}` 吞错 → 画布持模板 id，后续每次保存铸新 key。

## 四、结构性：双副本归一（单独批次）

design-workbench 与 definition-workbench **4690 行逐字节重复、仅 43 行 diff**，已出现单侧修复未回灌（def-wb 独有 `onWsCtxChange`）与成片死代码。三步走：

1. **短期（本方案纳入）**：差异收敛为运行时开关——同文件双注册 + `CFG.explorerMode: 'list'|'outline'`，物理副本归一（仍是单 Blob 模块，不受 native-page 不能 import 约束影响）。归一后上表所有"双份同病"修复只落一处。
2. 中期：若须保留两文件，脚本从真源生成变体 + CI diff 禁手改。
3. 长期：native-pages 宿主支持模块间共享依赖（import map / 共享 Blob chunk），根治共享约束。
