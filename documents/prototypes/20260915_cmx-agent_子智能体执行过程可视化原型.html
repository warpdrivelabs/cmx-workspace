场景 3 回放 · 重开会话后「查看完整过程」 S2
事后重开父会话，子任务卡默认折叠成一行；点卡上的「查看完整过程」懒加载子会话日志 （骨架屏一闪后渲染：提示词 + 思考卡 + 工具卡 + 引用组 + final，全部折叠态收好，逐个点开看）。 上一张是前台卡形态，下一张是后台回执卡形态——两条路径同形。后端零改动（get_events 本就能读子日志）。

场景 4 子会话审批 · 卡片出现在父视图 S3
现状：子智能体触发审批后事件落在子会话里，父界面永远看不到，子任务静默卡死。 改造后审批卡（金框）直接出现在父视图，点「批准」或「拒绝」子任务当场续跑——两条分支都试试点，再点「▶ 重播」换一支重走。

场景 5 恢复 · 刷新页面后后台任务仍在跑 S3
后台任务运行中刷新 / 重开会话：打开父会话时拉一次「活动子任务」清单，重建「后台执行中」卡，实时事件接着流。此为静态快照（无交互）。

方案映射：场景 1 / 2 = S1（总线信封加 parent + 子会话挂事件 sink）；场景 3 = S2（懒加载 get_events(subtask-…)）； 场景 4 / 5 = S3（活动子任务查询 + 审批透出）。v3 变更：卡内直接复用主会话渲染组件（思考卡 / 工具卡 / 上下文引用组 / bare 气泡）， 实施时 = 把 renderEvent 管线跑在子任务卡的内容器上，不另造样式。
