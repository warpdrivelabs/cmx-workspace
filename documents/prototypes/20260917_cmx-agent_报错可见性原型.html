痛点一句话：报错被折叠 CSS 藏掉（.turn.folded .meta{display:none}），收起后只剩一句没有信息量的 「— 回合异常结束 —」，原因要展开才能看到、看到了还是英文原文。
每个场景切到 「改后」 对比三件事：A 折叠着也能看到一行红色原因（点它展开全程）； B 原因是人话（说清该干什么），技术原文收在展开后的「详情」里；C 工具失败的 ✕ 行旁直接带一句原因摘要。
改后折叠态固定形态 = 「已工作 N 秒」+ 一行红色原因（限两行截断，悬停看全文，点击展开过程）——行数与现状一样，但原因看得见。 存量历史会话走同一渲染路径按「⚠ 处理出错」前缀识别，老数据自动生效，无需迁移。 飞书 IM 桥复用同一文案，友好话术三端（Web 壳 / 桌面壳 / IM）同时受益。
