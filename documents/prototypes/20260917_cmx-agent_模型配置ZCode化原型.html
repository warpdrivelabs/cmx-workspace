对齐 ZCode 设置页后的看点：①头行 = logo + 激活开关 + ⋯ 菜单（重命名 / 删除收进菜单），右上「＋ 添加供应商」打开模板目录，选模板一键预填 URL 和模型清单； ②API Key 行没有锁——默认打码、直接可改，点 👁 临时看明文；旁边「获取 API Key ↗」直达供应商控制台（小白不用上网搜）； ③「模型」是一张可管理的清单——行尾开关控制进不进聊天选择器（ZCode 同款：关闭=保留配置但不进选择器），没有「主模型」概念——当前用哪个模型在聊天 ◎ 选择器里选；[🧠 思考] 标记会输出思考过程的模型；每行 🧪 单测 / 🗑 移除，点模型名改名； ④底部「测试连接」，存之前先真发一条 1-token 的请求验一验。 模拟服务器返回：  ← 切换后点「测试连接」看不同报错的人话文案。
