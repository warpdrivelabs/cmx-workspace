CMX 本体平台（cmx-ontology :8097）

简要说明 3/4如何增加对象

先分清两层：对象类型（元数据，"客户"这种模板）和对象实例（数据，"客户 №1"这条记录）。加类型有四条路，加实例有五个操作。

一、加"对象类型"的四条路

途径做法适合
A · 设计工作台 UIexplorer 区底部「+ 对象类型」→ 右侧 Inspector 填属性（主键◇/必填/索引/语义类型）→ 保存日常单建，可视化
B · REST API先 POST /object-types/validate 校验，再 POST /object-types 落库脚本/程序化
C · DOC 导入POST /import/doc：主从实体图 → 多个对象类型 + 组合关系已有业务单据模型批量进本体
D · DCT 导入POST /import/dct：字典 → 参照对象类型 + 字典项种子数据主数据字典接入（见 4/4 篇）

途径 B 完整示例（可直接照抄）

# ① 先校验（只验不存，返回 valid / 错误信息）
curl -s -X POST http://127.0.0.1:8097/api/onto/v1/object-types/validate \
  -H "Content-Type: application/json" \
  -H "X-API-Key: cmx_sk_dev_A1b2C3d4E5f6G7h8I9j0K1l2M3n4O5p6" \
  -d '{ "apiName":"Customer","displayName":"客户",
        "primaryKey":"id","titleProperty":"name",
        "properties":[
          {"apiName":"id","baseType":"long","required":true},
          {"apiName":"name","baseType":"string","required":true,"isIndexed":true},
          {"apiName":"region","baseType":"string"},
          {"apiName":"createdAt","baseType":"timestamp"} ],
        "status":"active",
        "dam":{"domain":"客商域","application":"客户管理","module":"客户档案"} }'

# ② 校验通过后正式落库（同一份 JSON，换端点）
curl -s -X POST http://127.0.0.1:8097/api/onto/v1/object-types ...同上...

# ③ 配关系（客户 1:N 订单）
curl -s -X POST http://127.0.0.1:8097/api/onto/v1/link-types \
  -H "Content-Type: application/json" -H "X-API-Key: ..." \
  -d '{"apiName":"customerPlacesOrder","displayName":"客户下单",
       "objectTypeA":"Customer","objectTypeB":"Order",
       "cardinality":"oneToMany","roleA":"places","roleB":"placedBy"}'

必须知道的校验规则（后端强制）

  • apiName：字母或下划线开头，仅字母/数字/下划线；全局唯一（重名 upsert 覆盖，需谨慎）。
  • primaryKey / titleProperty 若指定，必须出现在属性列表里。
  • 属性 apiName 不得重复；baseType 支持 16 种（string/integer/long/double/decimal/boolean/date/timestamp/array/struct/attachment/mediaReference/marking/geohash/geoShape/vector）。
  • 关系类型两端（objectTypeA/B）必须已存在且非空。
  • 新建类型默认 experimental；active 表示稳定可用，发布后才进版本快照。

二、加"对象实例"的五个操作

操作调用要点
写单条POST /objects/{type}，body {"properties":{...}}pk/title 按 primaryKey/titleProperty 自动从 properties 抽取；重复写=upsert
批量写POST /objects/{type}/batch，body 为数组单事务，要么全写要么全不写
改（乐观锁）POST /objects/{type}/{pk}/modify，body {"set":{...},"expectedUpdatedAt":"..."}带 expectedUpdatedAt 防并发覆盖，冲突时返回 conflict + 当前值
建关系POST /links，body {"link":"...","aPk":"1","bPk":"101"}关系类型须先定义；幂等
删对象DEL /objects/{type}/{pk}连带清理该对象的所有关系边

实例写入 + 验证完整序列

# 写客户（返回 data.pk，数值自动转字符串）
curl -s -X POST .../api/onto/v1/objects/Customer \
  -H "Content-Type: application/json" -H "X-API-Key: ..." \
  -d '{"properties":{"id":1,"name":"北方贸易","region":"north"}}'

# 批量写订单（单事务 4 条）
curl -s -X POST .../api/onto/v1/objects/Order/batch \
  -d '[{"properties":{"oid":101,"no":"SO-101","amount":1500}},
       {"properties":{"oid":102,"no":"SO-102","amount":800}}]'

# 挂关系边：客户1 places 订单101
curl -s -X POST .../api/onto/v1/links \
  -d '{"link":"customerPlacesOrder","aPk":"1","bPk":"101"}'

# 验证：客户 1 → 他的订单（Search-Around 一跳）
curl -s ".../api/onto/v1/objects/Customer/1/links/customerPlacesOrder"
