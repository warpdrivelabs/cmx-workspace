# 菜单数据库化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 menu-pages 菜单数据从文件存储迁移到 `cmx_menu` 数据库表，CMXPortalManager 增加树形 CRUD 管理页并使已有"编辑菜单节点"弹框落库。

**Architecture:** 节点级映射到 `cmx_menu`（每节点一行，workspace/dialogspace 入 `definition` JSONB）；`/api/menu-pages` 改为 DB 回源（解析 menuRef 前 3 段查 domain/app/module，重建 ExplorerMenuNode 文档，嵌入 `_cmxId`）；`/api/menu/*` 全复用；编辑弹框 `openWithNode` 路径保存改走 `/api/menu/update`；迁移用 Node 脚本读菜单文件生成 INSERT SQL。

**Tech Stack:** Rust / axum / sqlx / PostgreSQL（后端 cmx-container）；原生 JS / UI5 WebComponents / Lit / Vite（前端 CMXPortalManager）；Node（迁移脚本）。

## Global Constraints

```rust
/// 解析点分 menuRef 前 3 段为 (domain, application, module)。
/// 段不足 3 返回 None（短 ref 不支持 DB 回源）。
fn parse_module_menu_ref(menu_ref: &str) -> Option<(&str, &str, &str)> {
    let segs: Vec<&str> = menu_ref.trim().split('.').collect();
    if segs.len() < 3 {
        return None;
    }
    for s in &segs[..3] {
        if s.is_empty() || !is_safe_segment(s) {
            return None;
        }
    }
    Some((segs[0], segs[1], segs[2]))
}
```

- [ ] **Step 3: 新增 `get_menu_page_json_from_db` —— 查询 + 重建文档**

```rust
/// 从 cmx_menu 按 domain/app/module 查询并重建菜单页文档。
///
/// 输出 `{version:1, source:"db", items:[<ExplorerMenuNode>]}`，每个节点嵌入
/// `_cmxId`（cmx_menu 主键）供编辑弹框调 `/api/menu/update` 定位。
async fn get_menu_page_json_from_db(menu_ref: &str) -> PortalResult<Value> {
    let Some((domain, application, module)) = parse_module_menu_ref(menu_ref) else {
        return Err(PortalError::bad_request(format!(
            "DB 菜单引用需至少含 domain.application.module 三段：{menu_ref}"
        )));
    };
    let (mm, db_id) = db_handle().await?;
    let sql = "SELECT id, code, name, icon, fun_code, sort_order, parent_id, definition \
               FROM cmx_menu WHERE domain_code = $1 AND application_code = $2 \
               AND module_code = $3 AND archived = 0 ORDER BY sort_order";
    let dataset: DataSet = mm
        .query_sql_with_datavalues(
            &db_id,
            None,
            sql,
            vec![
                DataValue::String(domain.to_string()),
                DataValue::String(application.to_string()),
                DataValue::String(module.to_string()),
            ],
            "menu_pages_db",
        )
        .await
        .map_err(|e| PortalError::internal(format!("查询菜单失败: {e}")))?;

    // 扁平节点收集：id(PK) -> 节点 JSON
    let schema = &dataset.schema;
    let mut nodes_by_pk: std::collections::HashMap<String, Value> = HashMap::new();
    let mut parent_of: std::collections::HashMap<String, Option<String>> = HashMap::new();
    let mut roots: Vec<String> = Vec::new();
    for row in dataset.iter() {
        let get = |name: &str| -> Option<String> { row.get_by_name_as(schema, name) };
        let pk = get("id").unwrap_or_default();
        let code = get("code").unwrap_or_default();
        let name = get("name").unwrap_or_default();
        let icon = get("icon");
        let fun_code = get("fun_code");
        let parent_id = get("parent_id");
        let definition: Value = row
            .get_by_name_as::<serde_json::Value>(schema, "definition")
            .unwrap_or(Value::Null);
        let def_obj = definition.as_object();

        let mut node = serde_json::Map::new();
        node.insert("id".into(), json!(code));
        // caption：优先 definition.caption（保留 i18n 对象），回退 name
        let caption = def_obj
            .and_then(|o| o.get("caption").cloned())
            .unwrap_or(json!(name));
        node.insert("caption".into(), caption);
        if let Some(ic) = icon {
            node.insert("icon".into(), json!(ic));
        }
        if let Some(fc) = fun_code {
            node.insert("permissionId".into(), json!(fc));
        }
        if let Some(def) = def_obj {
            for k in ["workspace", "dialogspace", "expanded", "type", "name"] {
                if let Some(v) = def.get(k) {
                    node.insert(k.into(), v.clone());
                }
            }
        }
        node.insert("_cmxId".into(), json!(pk)); // 供编辑弹框定位
        node.insert("children".into(), json!([]));

        nodes_by_pk.insert(pk.clone(), Value::Object(node));
        parent_of.insert(pk.clone(), parent_id);
        if parent_id.is_none() {
            roots.push(pk);
        }
    }
    // 组树：把每个节点挂到父节点的 children
    let mut all: Vec<Value> = nodes_by_pk.values().cloned().collect();
    // 用 parent_of 重建引用（需按 pk 取父 children 数组 push）
    // 先建 pk->index
    // 简化：多次遍历按 parent 挂载
    for (pk, parent_id) in &parent_of {
        if let Some(pid) = parent_id {
            if let Some(parent) = nodes_by_pk.get_mut(pid) {
                if let Some(arr) = parent.get_mut("children").and_then(|v| v.as_array_mut()) {
                    if let Some(child) = nodes_by_pk.get(pk) {
                        arr.push(child.clone());
                    }
                }
            }
        }
    }
    let items: Vec<Value> = roots
        .iter()
        .filter_map(|pk| nodes_by_pk.get(pk).cloned())
        .collect();
    let _ = all; // 抑制未用警告
    Ok(json!({ "version": 1, "source": "db", "items": items }))
}
```

> 注：`get_by_name_as`、`dataset.iter()`、`dataset.schema` 用法参照 `cmx-biz/src/menu/service.rs:933-949` 的 `row_to_tree_node`。`DataValue` 来自 `cmx_core::model::cell::DataValue`。编译时按实际 API 微调（row 取值 API 以 cmx-core dataset 为准）。

```js
// 读取 menu-pages JSON，展平树、计算树形字段、处理重复 code，输出 INSERT SQL。
import { readFileSync, writeFileSync } from 'node:fs'
import { resolve, dirname } from 'node:path'
import { fileURLToPath } from 'node:url'

const __dirname = dirname(fileURLToPath(import.meta.url))
const ROOT = resolve(__dirname, '..')
const DOCS = [
  { file: 'data/menu-pages/fi/cmxfico/gl/explorer-menu.json', domain: 'fi', app: 'cmxfico', module: 'gl' },
  { file: 'data/menu-pages/fi/cmxfico/report/report-menu.json', domain: 'fi', app: 'cmxfico', module: 'report' },
]

// 展平一个文档为节点数组（递归）
function flatten (items, parentCode, depth, codePath, idPath, domain, app, module, usedCodes, suffix) {
  const out = []
  items.forEach((node, i) => {
    let code = String(node.id ?? '')
    // 重复 code 处理：explorer 原样；report 冲突加 _rpt
    if (suffix && usedCodes.has(code)) code = code + '_rpt'
    usedCodes.add(code)
    const id = `${domain}.${app}.${module}/${code}`
    const newCodePath = codePath + '/' + code
    const newIdPath = idPath + '/' + id
    const caption = node.caption
    const name = typeof caption === 'string' ? caption : (node.name ?? code)
    const definition = {
      caption,
      ...(node.workspace ? { workspace: node.workspace } : {}),
      ...(node.dialogspace ? { dialogspace: node.dialogspace } : {}),
      ...(node.expanded != null ? { expanded: node.expanded } : {}),
      ...(node.type ? { type: node.type } : {}),
      ...(node.name ? { name: node.name } : {}),
    }
    const children = Array.isArray(node.children) ? node.children : []
    out.push({
      id, code, name: String(name), icon: node.icon ?? null, fun_code: node.permissionId ?? null,
      sort_order: i + 1, definition, domain_code: domain, application_code: app, module_code: module,
      parent_id: parentCode ? `${domain}.${app}.${module}/${parentCode}` : null,
      parent_code: parentCode, depth, leaf: children.length === 0 ? 1 : 0,
      code_path: newCodePath, id_path: newIdPath,
    })
    out.push(...flatten(children, code, depth + 1, newCodePath, newIdPath, domain, app, module, usedCodes, suffix))
  })
  return out
}

function sqlVal (v) {
  if (v == null) return 'NULL'
  if (typeof v === 'number') return String(v)
  return `'${String(v).replace(/'/g, "''")}'`
}
function sqlJson (obj) {
  return `'${JSON.stringify(obj).replace(/'/g, "''")}'::jsonb`
}

const usedCodes = new Set()
const all = []
// explorer 先导（suffix=false，原样）
for (const d of DOCS) {
  const doc = JSON.parse(readFileSync(resolve(ROOT, d.file), 'utf8'))
  const items = Array.isArray(doc) ? doc : (doc.items ?? [])
  const suffix = d.module === 'report' // report 冲突加 _rpt
  all.push(...flatten(items, null, 1, '', '', d.domain, d.app, d.module, usedCodes, suffix))
}

const cols = 'id, code, name, icon, fun_code, sort_order, definition, domain_code, application_code, module_code, parent_id, parent_code, depth, leaf, code_path, id_path, visible, status, open_type, archived, create_time, update_time'
const lines = all.map(n => {
  const vals = [
    sqlVal(n.id), sqlVal(n.code), sqlVal(n.name), sqlVal(n.icon), sqlVal(n.fun_code),
    sqlVal(n.sort_order), sqlJson(n.definition), sqlVal(n.domain_code), sqlVal(n.application_code), sqlVal(n.module_code),
    sqlVal(n.parent_id), sqlVal(n.parent_code), sqlVal(n.depth), sqlVal(n.leaf), sqlVal(n.code_path), sqlVal(n.id_path),
    '1', '1', '0', '0', 'now()', 'now()',
  ]
  return `INSERT INTO cmx_menu (${cols}) VALUES (${vals.join(', ')}) ON CONFLICT (code) DO NOTHING;`
})

const up = `-- 菜单文件迁移到 cmx_menu（由 scripts/gen_menu_migration.mjs 生成，可重跑）\n${lines.join('\n')}\n`
writeFileSync(resolve(ROOT, 'docs/sql/migrations/20260716_001_menu_pages_to_cmx_menu.up.sql'), up)

const down = `-- 回滚：清理迁移导入的菜单\nDELETE FROM cmx_menu WHERE domain_code='fi' AND application_code='cmxfico' AND module_code IN ('gl','report');\n`
writeFileSync(resolve(ROOT, 'docs/sql/migrations/20260716_001_menu_pages_to_cmx_menu.down.sql'), down)

console.log(`生成 ${all.length} 条 INSERT`)
```

```js
/**
 * 封装 cmx-container 的 /api/menu/* 接口。
 * 走全局 fetch 拦截器（自动加 Bearer + 拆 ApiResp 信封到 data）。
 */
const BASE = '/api/menu'

async function readErrorMessage (res) {
  let msg = res.statusText || `HTTP ${res.status}`
  try {
    const j = await res.json()
    if (j && typeof j.msg === 'string') msg = j.msg
    else if (j && typeof j.error === 'string') msg = j.error
  } catch { /* noop */ }
  return msg
}

async function req (path, init) {
  const res = await fetch(`${BASE}${path}`, init)
  if (!res.ok) throw new Error(await readErrorMessage(res))
  return res.json()
}

/** GET /api/menu/tree —— 按域/应用/模块加载菜单树 */
export async function getMenuTree (params) {
  const q = new URLSearchParams()
  if (params?.domain_code) q.set('domain_code', params.domain_code)
  if (params?.application_code) q.set('application_code', params.application_code)

}
```
