这是什么：Oracle EBS R12 总账（GL）的 Enter Journals（凭证录入） 界面仿真——Oracle Forms 风格，自上而下是 Batch（批）→ Header（头）→ Lines（行） 三层，对应三张表。
对应表字段：批区 → GL_JE_BATCHES（批名 NAME、期间 PERIOD_NAME、余额类型 ACTUAL_FLAG、控制总额 CONTROL_TOTAL、状态 STATUS=U）； 头区 → GL_JE_HEADERS（账本 LEDGER_ID、类别 JE_CATEGORY、来源 JE_SOURCE、币种 CURRENCY_CODE、会计日期、文档序列 DOC_SEQUENCE_VALUE）； 行区 → GL_JE_LINES（科目组合 CODE_COMBINATION_ID=CCID、ENTERED_DR/CR 输入币借贷、ACCOUNTED_DR/CR 本位币借贷、DESCRIPTION）。
与 SAP 的关键差异：科目是 CCID 代码组合（公司-成本中心-科目-板块 多段，如 21-500-1122-MARKETING），不是单一科目 + 维度列；借贷为 DR/CR 分列，不是金额 + 借贷标志；底部 Post（过账）按钮在差额 0 时才可执行。
