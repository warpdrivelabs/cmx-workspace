## 1. 端到端链路：列定义如何变成单元格

### 1.1 分派流程

```
CmxColumnModel (members: CmxColumn | CmxColumnGroup)
   │
   │ setColumnModel(model)
   ▼
cmx-revo-grid._applyColumnModel(model)
   │  CmxColumnAdapter.toRevoGrid(model)         ← cmx-column-adapter.js
   │     └─ col.toDescriptor()                   ← cmx-column.js:148
   │     └─ _leafDescriptorToRevoCol(d)          ← column-adapter.js:694
   │           ├─ readonly = (editMode ∈ {'readonly','none'})
   │           ├─ columnType='numeric' (当 isNumericDescriptor)
   │           ├─ _cmxType = _cmxTableType(d)    ← column-adapter.js:358  ★类型判定核心
   │           ├─ cellTemplate = buildDisplayCellTemplate(d)   ← 渲染器
   │           ├─ cellProperties = buildCellProperties(d)      ← 对齐/条件样式
   │           ├─ _cmxOnChange = d.calcFormula                 ← 计算列
   │           └─ _cmxCol = {真实 CmxColumn 引用}
   ▼
cmx-revo-grid._syncToRevo()                      ← revo-grid.js:806
   │  ① this._revo.editors = {...getRegisteredGridEditors()}   ← 灌入注册表编辑器
   │  ② applyRegisteredFieldTypesToColumns(columns)            ← revo-grid.js:1669
   │       └─ 对每列：typeName = col._cmxType || col._cmxCol.type
   │            def = getFieldType(typeName)
   │            若 def.grid.editor 存在且列未自带 → col.editor = typeName
   │            若 def.grid.cellTemplate 存在且列未自带 → col.cellTemplate = ...
   ▼
<revo-grid> 渲染：有 cellTemplate 用它，否则默认文本格
            编辑：列有 editor（字符串名）→ 查 editors[name] → 调 EditorCtr(colData, save, close)
```

### 1.2 类型判定核心 `_cmxTableType`（column-adapter.js:358-363）

```
em = editModeKind(edit.mode || editMode)        ← cmx-field-uicontrol.js:69
if em ∈ {'readonly','none'}        → 'readonly'
if em ∈ {'select','ref','combo','ignite-combo','dict-select'} → em
else → cmxTypeFromDataType(d)：
        numeric → 'number'，datetime → 'datetime'，date → 'date'，boolean → 'checkbox'，兜底 'text'
```

**两个核心扩展点（都支持零框架改动）**：
- `registerFieldType(name, {form, grid})` —— 加编辑器 + 单元格渲染
- `registerColumnPreset(name, {apply, format})` —— 加格式化/计算

### 1.3 表格组件清单

| 组件 | 底层引擎 | 编辑器/渲染器机制 |
|---|---|---|
| `<cmx-revo-grid>` | RevoGrid v4 (Stencil) | **完整支持** editors map + cellTemplate（主战场） |
| `<cmx-ignite-grid>` | Ignite UI igc-grid | **未接注册表**，编辑用 igc 原生 |
| `<cmx-tabulator>` | Tabulator 6 | treegrid 专用，未挂字段类型注册表 |
| `<cmx-ui5-form>` | UI5 | 表单端（非表格），与 grid 共享注册表 `form` 半边 |

> ⚠️ **编辑器/渲染器扩展机制只在 `<cmx-revo-grid>` 上完整落地**。

## 4. 编辑器实现现状

### 4.1 编辑器生命周期（RevoGrid v4 EditorBase 约定）

注册表里的 `grid.editor(colData, save, close)` 返回对象，RevoGrid 按序调用：

1. `render(h)` —— Stencil h 函数，返回 VNode（占位 `<div>`）
2. `componentDidRender()` —— 此时 `this.element` 指向根元素，在此 `document.createElement` + `appendChild` 挂真正的 web component（**项目统一范式**，避开 Stencil 对 web component 子 VNode 的解析限制）
3. `getValue()` —— 失焦/回车时取值提交
4. `beforeAutoSave(val)` —— 返回 false 跳过自动保存
5. `disconnectedCallback()` —— 卸载清理

`save(val, preventFocus?)` 由编辑器在用户确认时主动调用。

### 4.2 已注册编辑器清单

| edit.mode | 注册类型名 | grid 编辑器组件 | 注册位置 |
|---|---|---|---|
| `cmx-text-input` | text/input/cmx-text-input | `<cmx-text-input>` | builtin-field-types.js:557 |
| `cmx-number-input` | number | `<cmx-number-input>` | :562 |
| `cmx-date-input` | date | `<cmx-date-input>` | :568 |
| `cmx-datetime-input` | datetime | `<cmx-datetime-input>` | :574 |
| `select` | select | `<ui5-select>` + `<ui5-option>` | :381 |
| `combo` | combo | `<cmx-combo-box>`（list/tree/grid 三态） | :103 |
| `ignite-combo` | ignite-combo | `<cmx-ignite-combo>` | :248 |
| `cmx-dict-select` | dict-select | `<cmx-dict-select>` | cmx-dict-field-type.js:353 |
| （color） | color | `<input type="color">` | builtin:34 |

基础输入四件套（text/number/date/datetime）由通用工厂 `makeInputGridEditor(tag, type, norm)` 统一生成，form 端用 `makeInputFormImpl`——**form 与 grid 同款组件，零重复**。

## 6. 三元定义 → CmxColumn 映射现状

### 6.1 FLC 的 `_fieldToColumn`（最完整的映射）

文件：`flexible-combination-engine.js:424-515`。这是目前唯一一条「认真做映射」的路径，但**为弹性组合场景特化**（依赖 dimension/refDict 带出）。

**已映射**：

| FieldSpec | CmxColumn | 状态 |
|---|---|---|
| `id` / `caption`（必填加 `* `） | `id` / `caption` | ✅ |
| `dataType`（base 优先，否则按 dimType 推断） | `dataType` | ✅ |
| `fieldLength` / `intDigits` / `decimalDigits` | `length` / `integerDigits` / `decimalDigits` | ✅ |
| `edit.mode`（经 `_colEditMode`） | `edit.mode` | ⚠️ 部分（见 7.3） |
| `edit.required` / `requiredWhen` / `readonlyWhen` / `placeholder` | 同名 | ✅ |
| `validations` / `pattern` | `edit.validate`（编译成数组） | ✅ |
| `formula` + `dependsOn` | `calcFormula`（函数式） | ✅ |
| `display.decimals/zeroBlank/thousand` | `display.decimalDigits/zeroAsBlank/thousandSeparator`（别名映射） | ✅ |
| `display.negativeColor/align/format/mode` | 同名 | ✅ |
| `column.{width,frozen,visible,agg,align,display,edit}` | 覆盖层（优先级最高） | ✅ |
| dimension 字段的 refDict → `_dictSettingsForField` | `edit.{dictCode,idCol,codeCol,labelCol,parentCol,hierarchical,helpLayout,writeBack,dependents,...}` | ✅ |
| `enumValues`（非维度） | `edit.options` + 强制 select | ✅ |

**被丢弃或「搭乘」不消费**（schema 声明了但 `_fieldToColumn` 没落到结构化块）：

| FieldSpec | 去向 | 缺口 |
|---|---|---|
| `defaultValue` | 搭乘顶层 | CmxColumn 无 defaultValue 概念；新建行不自动填 |
| `unique` | 搭乘顶层 | 唯一约束不落地 |
| `searchable` / `filterable` | 搭乘顶层 | grid 无搜索/筛选消费 |
| `sensitive` | 搭乘顶层 | 无脱敏渲染 |
| `i18n` | 搭乘顶层 | 多语言编辑开关不落地 |
| `unitField` | 搭乘顶层 | 无单位字段联动渲染 |
| `nullable` / `isPrimaryKey` | 搭乘顶层 | 不建模 |
| `edit.editableWhen`（DCT/DOC schema 有） | 未透传 | **CmxColumn.edit 无此键** |
| `edit.visibleWhen`（DOC schema 有） | 未透传 | **CmxColumn 无此键**（仅静态 visible） |
| `edit.validateWhen` | 未透传 | CmxColumn.edit 有此键但 FLC 引擎没写过去 |

### 6.2 DOC 的 `buildColumnModel`（最薄弱）★

文件：`cmx-doc-meta-loader.js:108-122`。**只消费 6 个属性**：

```js
new CmxColumn({
  id: c.name,
  caption: c.caption || c.name,
  dataType: c.dataType || 'VARCHAR',
  width: defaultWidth(c.dataType, c.name),
  align: alignFor(c.dataType),
  editMode: (c.isPrimaryKey || SYSTEM_COLS.has(c.name)) ? 'readonly' : undefined,
})
```

DOC 元数据列上即使带了 `edit.mode / dimType / agg / refDict / displayField / fieldLength / decimalDigits / nullable / pattern / enumValues / display`，**这条装载路径全部丢弃**。典型表现：
- DOC 金额列的 `decimalDigits:4` 被忽略，一律走 grid 默认 2 位
- DOC 的 `refDict`（如 `account_id → gl_account`）不生成 dictSettings，退化成裸文本输入
- DOC 没有 display/format 概念，千分位/负数红字全走默认

### 6.3 DCT 字典

库内**没有** `dctFieldsToColumns` 这样的映射函数。DCT 字段消费的入口有两条：
1. 作为 FLC 维度的取数配置（`_dictSettingsForField`）——只取字典元信息，不生成 DCT 字段本身的列
2. 作为 dict-select 编辑器的数据源（`dictCfgFromField`）

DCT 字段自身的 `dataType/caption/edit.mode` 没有被库内任何映射函数转成 CmxColumn，需要调用方自行 `new CmxColumn(...)`。

### 6.4 field-override 能补什么

`effectiveField` = `deepMerge(baseField, override)`，理论上可改字段对象任何顶层键，但 `diagnoseOverride` 硬性禁止改两类：
- **身份键**：`id`/`name`（报 `OVERRIDE_CHANGES_IDENTITY`）
- **物理类型键**：`dataType`/`fieldLength`/`intDigits`/`decimalDigits`（报 `OVERRIDE_CHANGES_PHYSICAL_TYPE`）

覆盖层**能改**：`caption`、`edit.*`、`display.*`、`refDict`/`refField`/`displayField`、`agg`、`defaultValue`、`enumValues`、`pattern`、`validations`、`column.*`。

覆盖层**补不了**：
- 新增 CmxColumn 不支持的语义键（sensitive/searchable/filterable/unitField 写上去也只搭乘）
- 改变 edit.mode 的运行时实现缺失（覆盖成 image 后注册表无编辑器仍退化）
- **补 DOC 装载路径的丢弃**（field-override 是定义编辑器侧机制，但 `buildColumnModel` 运行时装载根本不读字段上的 edit/display 覆盖）

## 7. 缺口诊断（核心）

按严重程度分四层。

### 第一层：DOC 装载路径几乎「裸奔」—— 最严重

`cmx-doc-meta-loader.js:108-122` 只消费 6 个属性。DOC 元数据已有的 `edit.mode/dimType/agg/refDict/displayField/fieldLength/decimalDigits/nullable/pattern/enumValues/display` 全部丢弃。

**改造方向**：需要一个类似 FLC `_fieldToColumn` 的完整映射函数，把 DOC 字段的编辑/渲染语义真正落到 CmxColumn。这是让 DOC 定义能驱动表格编辑/渲染的**前置条件**。

### 第二层：CmxColumn 已支持、但三元 schema 无录入入口

CmxColumn 运行时已实现，但 `cmx-field-schema.js` 的 FIELD_SCHEMA 没有对应录入项，三元定义的设计器 UI 表达不了：

| CmxColumn 已支持 | 三元 schema 入口 | 影响 |
|---|---|---|
| `display.badgeMap`（值→{text,color,icon}） | 无 | 状态列无法变徽章 |
| `display.icon` / `display.link` | 无 | 无法做图标列/链接列 |
| `display.cellStyle`（条件样式） | 无 | 无法「value<0 标红」 |
| `display.emptyText` | 无 | 无法定义空值占位符 |
| `edit.trigger`（click/dblclick） | 无 | 无法控制何时打开编辑器 |
| `edit.dropdownColumns`（下拉列模型） | 无 | 无法定义下拉弹窗里的列 |
| `edit.displayTemplate`（`${code} - ${name}`） | 无 | 无法定义组合显示文本 |
| `edit.parent`（tree 父字段） | 无 | 无法定义树形编辑器父子关系 |
| `edit.source`（远端数据源） | 无 | 无法绑定 pageService |

**改造方向**：在 `cmx-field-schema.js` 的 FIELD_SCHEMA 里为这些键补录入选（按端 DCT/DOC/FLC 裁剪 appliesTo）。

### 第三层：运行时编辑器实现缺失

| edit.mode | EDIT_MODES 值域 | 注册表 | 实际行为 |
|---|---|---|---|
| `cmx-textarea-input` | ✅ 有 | ❌ 无 | 退化文本 |
| `cmx-richtext-input` | ✅ 有 | ❌ 无 | 退化文本 |
| `image` | ✅ 有 | ❌ 无 | 退化文本 |
| `video` | ✅ 有 | ❌ 无 | 退化文本 |
| `ref` | ✅ 有 | ❌ 无（adapter 认但无 editor） | 需配成 combo/dict-select |

**改造方向**：在 `cmx-builtin-field-types.js`（或新建 `cmx-xxx-field-type.js` 副作用模块）用 `registerFieldType` 注册对应编辑器。

### 第四层：语义键建模缺口

三元 schema 可填，但 CmxColumn 没有对应建模，grid 端不消费：

| 三元 schema 键 | CmxColumn 状态 | 缺口 |
|---|---|---|
| `defaultValue` | 无此键 | 新建行不自动填默认值 |
| `unique` | 无此键 | 唯一约束不落地 |
| `sensitive`（PII 脱敏） | 无此键 | 无脱敏渲染 |
| `searchable` / `filterable` | 无此键 | grid 无搜索/筛选消费 |
| `unitField`（计量单位联动） | 无此键 | 金额列无法带单位后缀 |
| `i18n` | 无此键 | 多语言编辑开关不落地 |
| `nullable` / `isPrimaryKey` | 搭乘顶层不建模 | DOC loader 单独处理成 readonly |
| `edit.editableWhen`（DCT/DOC schema 有） | **CmxColumn.edit 无此键** | 条件可编辑无法消费 |
| `edit.visibleWhen`（DOC schema 有） | **CmxColumn 无此键** | 条件可见无法消费 |
| `edit.validateWhen`（CmxColumn 有） | **FLC 引擎没写过去** | 条件校验断链 |

**改造方向**：这些键需要在 CmxColumn 建模 + grid 端消费逻辑 + FLC/DOC 映射函数三处同步补。其中 `editableWhen`/`visibleWhen`/`validateWhen` 是条件表达式，grid 端需在 `beforeedit`/渲染时求值。

### 三元字段定义结构对比（速查）

| 语义 | DCT | DOC | FLC | CmxColumn |
|---|---|---|---|---|
| 录入控件 | `edit.mode` | `edit.mode` | `edit.mode` | `edit.mode` |
| 条件必填 | `edit.requiredWhen` | `edit.requiredWhen` | `edit.requiredWhen` | `edit.requiredWhen` |
| 条件可编辑 | `edit.editableWhen` | `edit.editableWhen` | — | **无** |
| 条件只读 | — | — | `edit.readonlyWhen` | `edit.readonlyWhen` |
| 条件可见 | — | `edit.visibleWhen` | — | **无**（仅静态 visible） |
| 条件校验 | — | — | — | `edit.validateWhen`（三元无） |
| 默认值 | `defaultValue` | `defaultValue` | `defaultValue` | **无** |
| 公式 | — | — | `formula` | `calcFormula` |
| 引用字典 | `refDict` | `refDict` | `refDict` | （编译进 editSettings） |
| 显示模式 | — | — | `display.mode` | `display.mode`（DOC 不落地） |
| 徽章映射 | — | — | — | `display.badgeMap`（三元无入口） |
| 条件样式 | — | — | — | `display.cellStyle`（三元无入口） |
| 计量单位 | — | — | `unitField` | **无** |

## 8. 扩展指引

### 8.1 加一个新编辑器（最小改动，零框架改动）

```js
import { registerFieldType } from 'cmx-data-comp'

registerFieldType('rating', {
  form: { create(field, ctx){...}, write(editor, raw){...} },
  grid: {
    editor(colData, save, close){
      return {
        render(h){ return h('div', { ref: 'slot' }) },
        componentDidRender(){
          const el = document.createElement('my-rating')
          el.value = colData.model[colData.prop]
          el.addEventListener('change', () => save(el.value))
          this.element.appendChild(el)
        },
        getValue(){ /* 失焦兜底取值 */ },
        disconnectedCallback(){ /* 清理 */ },
      }
    },
    cellTemplate(h, props){ /* 只读渲染 */ },
  },
})
```

**配套**（让设计器能选）：
- `cmx-field-uicontrol.js`：`EDIT_MODES` 加 `'cmx-rating'`；`EDIT_MODE_RUNTIME_KINDS` 映射（可选）
- `cmx-field-schema.js`：`EDITOR_PROPERTY_SCHEMA` 加 `'cmx-rating'` 的属性列表
- 业务入口 `import './lib/cmx-rating-field-type.js'`（副作用注册）

**无需改**：cmx-revo-grid、cmx-column-adapter、cmx-ui5-form（都通过注册表自动发现）。

### 8.2 加一个新渲染/格式化（最小改动）

```js
import { registerColumnPreset } from 'cmx-data-comp'

registerColumnPreset('currency-cn', {
  format(row, { value, args }) {
    return (Number(value) || 0).toLocaleString('zh-CN', { style: 'currency', currency: args?.ccy || 'CNY' })
  },
})
// 用：new CmxColumn({ id:'amount', displayMask:{preset:'currency-cn', args:{ccy:'USD'}} })
```

**无需改**：adapter、revo-grid（`buildDisplayCellTemplate` → `formatByPreset` 已能消费任意 preset 名）。

### 8.3 加一个声明式计算（最小改动）

registerColumnPreset('fx-convert', {
  apply(row, { args }) {
    row[args.target] = Math.round(row[args.amount] * row[args.rate] * 100) / 100
  },

const members = cols.map((c) => new C.CmxColumn({
  id: c.name,

### 8.5 ⚠️ 不要动的雷区

`cmx-column-adapter._cmxTableType`（:358-363）的分派逻辑牵动 form/grid/ui5-table/ignite/ag-grid 五端适配。当前设计已把「新类型识别」收敛到 `_cmxType` + 注册表，**应尽量只在注册表层加新类型，不动 adapter 分派**。

### 8.6 registerFieldType 接口契约

一个字段类型对象可声明两面：

**`form` 端**（cmx-ui5-form 用）：
- `create(field, ctx) -> HTMLElement` —— 创建编辑器 DOM；用 `ctx.commit(field, v)` 提交
- `write(editor, raw, field, ctx) -> void` —— 回填值到编辑器

**`grid` 端**（revo-grid 用）：
- `editor(colData, save, close) -> EditorBase` —— 返回编辑器对象（见 4.1 生命周期）
- `cellTemplate(h, props) -> VNode|string` —— 只读单元格自定义渲染

完整样例参考 `cmx-dict-field-type.js:353-440`（dict-select 的四钩子实现）。
