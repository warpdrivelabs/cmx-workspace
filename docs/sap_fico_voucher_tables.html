SAP FICO 会计凭证相关表结构

覆盖 SAP ERP（ECC 及 S/4HANA 兼容）财务会计（FI）会计凭证相关的经典数据表：凭证抬头/行项目/税务、未清已清索引、跨公司、New GL（新总账）行项目与汇总、经典总账余额、科目与客商主数据、变更凭证、编号范围与凭证控制配置。本文档不包含 S/4HANA 的 ACDOCA（Universal Journal 通用日记账）表。

核心：BKPF 抬头 · BSEG 行项目 · BSET 税务 主键：MANDT+BUKRS+BELNR+GJAHR(+BUZEI) 借贷：金额 + 借贷标志 SHKZG 不含 ACDOCA
点目录跳转 · 关键词实时过滤卡片
阅读提示：会计凭证的“真身”是 BKPF（抬头）+ BSEG（行项目）。BSEG 是簇表（Cluster Table，物理存于 RFBLG 簇），不能任意 SQL 查询，因此 SAP 用 BSID/BSAD（客户）、BSIK/BSAK（供应商）、BSIS/BSAS（总账）等二级索引表按未清（Open）/已清（Cleared）冗余存储，供快速查询。S/4HANA 中行项目并入 ACDOCA（本文档不展开），上述索引表多改为兼容用的 CDS 视图。

关系总览（凭证如何串起来）

① 凭证主体（一张凭证）
BKPF（抬头, 1）── BELNR+BUKRS+GJAHR ──< BSEG（行项目, N）──< BSET（税务行, N）

② 行项目 → 二级索引（按账户类型冗余，便于查询）
BSEG（KOART=D 客户行）→ BSID/BSAD（客户 未清/已清）
BSEG（KOART=K 供应商行）→ BSIK/BSAK（供应商 未清/已清）
BSEG（KOART=S 总账行, 开未清管理）→ BSIS/BSAS（总账 未清/已清）

③ 行项目 → 主数据（科目/客商）
BSEG.HKONT/SAKNR → SKA1/SKB1/SKAT（总账科目）
BSEG.KUNNR → KNA1/KNB1（客户）　·　BSEG.LIFNR → LFA1/LFB1（供应商）

④ 行项目 → 余额汇总
经典：BSEG → GLT0　·　New GL：FAGLFLEXA（行）→ FAGLFLEXT（余额）

⑤ 跨公司 / 冲销 / 变更 / 取号
跨公司：BVOR.BVORG 串多张 BKPF　·　冲销：BKPF.STBLG/STJAH 指向红冲凭证
变更留痕：CDHDR/CDPOS（OBJECTCLAS=BELEG）　·　凭证取号：NRIV（对象 RF_BELEG）
