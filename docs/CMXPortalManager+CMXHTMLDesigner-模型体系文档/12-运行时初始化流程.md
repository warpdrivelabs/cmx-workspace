> 本章把前面 11 章串起来，画一张从"开发者拖拽保存"到"用户在 Portal 看到内容"的完整链路。

## 2. 设计器侧：保存

```mermaid
sequenceDiagram
    autonumber
    participant Dev as 开发者
    participant PD as Page Data Models
    participant Meta as __designer_meta__
    participant FS as 文件系统 / Server

    Dev->>PD: 拖入 CmxDataSet 卡片
    PD->>PD: 生成 instance { id, modelType, instanceId, props, events }
    Dev->>PD: 填 props（如 dataSource='loadItems'）
    Dev->>PD: 写事件脚本
    Dev->>FS: 点保存
    FS->>FS: 序列化 models 数组进 __designer_meta__
    FS->>FS: 写入 HTML 页面源文件
```

最终 `__designer_meta__` 大致这样：

```jsonc
{
  "pageData":       [ /* $data 变量 */ ],
  "pageFns":        [ /* pageFns 函数 */ ],
  "pageServices":   [ /* pageServices */ ],
  "pageDeps":       [ /* import 声明 */ ],
  "pageInterfaces": [ /* 页面接口 */ ],
  "dataFlow":       { /* 兼容老配置 */ },
  "models": [
    { "modelType": "CmxDataSet",     "instanceId": "itemsDs",   "props": {...}, "events": {...} },
    { "modelType": "CmxColumnModel", "instanceId": "itemsModel", "props": {...}, "events": {...} },
    { "modelType": "CmxMasterSlave", "instanceId": "ms",        "props": {...}, "events": {...} },
    { "modelType": "FlexibleCombination", "instanceId": "detailFC", "props": {...}, "events": {...} }
  ]
}
```

## 3. 运行时：完整初始化流程

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户
    participant Portal as CMXPortalManager
    participant H as 页面 host
    participant Block as buildCmxScriptBlockFromPageState
    participant Init as initPageModels
    participant DS as CmxDataSet
    participant CM as CmxColumnModel
    participant MS as CmxMasterSlave
    participant FC as FlexibleCombination
    participant DCT as CmxDCTMeta
    participant V as 可视组件
    participant Svc as pageService

    U->>Portal: 点击菜单「凭证录入」
    Portal->>H: 加载 voucher.html + 注入 globalThis.workspace
    H->>Block: 读 __designer_meta__
    Block->>Block: 编译脚本（含 pageFns / pageServices / importmap）
    Block-->>H: 注入到 <script> 块
    H->>H: connectedCallback 触发
    H->>Init: initPageModels(__designer_meta__.models)
    Init->>DS: new CmxDataSet(props)
    Init->>CM: new CmxColumnModel(props)
    Init->>MS: new CmxMasterSlave(props)
    Init->>FC: new FlexibleCombination(props)
    Init->>DCT: new CmxDCTMeta(props) [可选]
    Init-->>H: 挂到 host.<instanceId>
    Init->>V: 创建可视组件 (connectedCallback)
    V->>DS: setDataSet(itemsDs) [若 data-cmx-dataset-id]
    V->>CM: setColumnModel(itemsModel) [若 data-cmx-model-id]
    V->>MS: bindForm / bindTable (从 data-cmx-dataset-id 推断 path)
    H->>Svc: 调 loadItemsService (onInit)
    Svc-->>DS: rows[]
    DS-->>V: 派发 ds-row-added
    V-->>U: 渲染表格
    U->>V: 选某行
    V->>FC: 通知锚点变化
    FC->>CM: setMembers(新列)
    CM-->>V: 派发 columns-changed
    V-->>U: 表格列变化
```

> 来源：[init-page-models.js](file:///media/yqs/工作/rustspace/cmx/packages/cmx-data-comp/src/lib/init-page-models.js) + [packages/cmx-data-comp/CLAUDE.md](file:///media/yqs/工作/rustspace/cmx/packages/cmx-data-comp/CLAUDE.md)

## 6. 服务调用与数据流

```mermaid
sequenceDiagram
    participant Init as initPageModels
    participant DS as CmxDataSet
    participant Svc as pageService
    participant Grid as <cmx-revo-grid>

    Init->>DS: 创建实例
    Init->>DS: 注册 dataSource = 'loadItems'
    Init->>DS: onInit → 调 host.loadItems(params)
    DS->>Svc: 调 pageService
    Svc-->>DS: rows[]
    DS->>DS: setRows(rows)
    DS-->>Grid: 派发 ds-row-added × N
    Grid-->>Grid: 渲染
```

> 关键点：`pageService` 编译后的签名是 `(params, _opts)`，`AbortSignal` 通过 `_opts.signal` 自动传入。

sequenceDiagram

## 9. 常见运行时问题排查

| 现象 | 可能原因 |
| --- | --- |
| `host.<instanceId>` 是 undefined | models 数组里漏了这个 modelType / instanceId 拼错 |
| 表格没数据 | `dataSource` 没填 / `dataSourceEvent` 不是 `onInit` / service 404 |
| 列没出现 | `columnModelId` 拼错 / 列模型 `columns=[]` 且没 FC 触发 |
| 聚合不工作 | `aggregations` 的 `from/to/toField` 路径写错 |
| 事件没触发 | 事件名拼错（区分大小写）/ 脚本语法错误 |
| FC 静默失败 | `columnModelId` 目标不存在 / inlineData 解析失败（控制台有 warn） |

---

## 小结

- **设计期** = 配 `models` 数组，序列化进 `__designer_meta__`
- **运行期** = `initPageModels` 按 `modelType` 创建实例，挂到 `host.<instanceId>`
- **视图绑定** = `data-cmx-dataset-id` / `data-cmx-model-id` DOM 属性自动桥接
- **数据流** = pageService → DataSet → 可视组件
- **列变更流** = 锚点变化 → FC → Engine → setMembers → 可视组件
